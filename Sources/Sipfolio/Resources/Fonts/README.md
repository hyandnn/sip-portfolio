# Fusion Pixel Font

Sipfolio 0.6.0 embeds the unchanged Simplified Chinese 12px proportional OTF from the upstream 2026.09.25 release. The font is registered only within the running app process; it is not installed as a system font.

Upstream: https://github.com/TakWolf/fusion-pixel-font

Release: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.25

Copyright and license: see `OFL.txt` and the included upstream notices under `LICENSES/`. The font is distributed under SIL Open Font License 1.1. Source outlines and font names were not modified.

Small interface text uses the native 12-point grid and headings use 24 points. Cocktail photos and bottle stickers keep their original visual content.
