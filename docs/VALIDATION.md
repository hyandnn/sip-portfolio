## 验证边界

实际文件选择、照片拖放、点击保存、详情编辑／删除对话框、PNG 保存面板的端到端 UI 操作尚未自动验证。仅验证了底层业务和图片管线，以及视图布局。

受限执行环境中的 Vision 测试无法加载 Neural Engine 模型；相同测试在本机正常权限下通过。Release 构建的调试符号生成和图标转换也在本机正常权限下完成。

## 建议首次使用的验收步骤

1. 点击「新收藏」，导入一张自己的酒瓶照片。
2. 检查贴纸预览；多个主体时选择酒瓶，失败时重试或明确选择原图。
3. 填写酒名、类别、备注并保存。
4. 从收藏墙打开详情，修改备注并导出 PNG。
5. 退出并重新打开，确认记录和照片仍在。
6. 可创建一条临时测试收藏，检查删除确认与取消行为。
