# 后续方向

以下为尚未实现或尚未完成的方向，不是版本承诺。当前可用功能见 [README](../README.md)，已经完成的变更见 [CHANGELOG](../CHANGELOG.md)。

- **备份与恢复**：在现有整目录手动备份基础上增加校验、导出与恢复界面。
- **配方使用体验**：独立份量计算、mL／oz 展示及调配后的个人记录；继续保留来源原用量。
- **贴纸编辑**：裁剪、描边调整及复杂背景下的主体选择。
- **资料质量**：扩大可追溯配方覆盖，改善明确版本和小众喝法匹配，保持手动核对与换图入口。
- **人工验收与分发**：补齐原生文件选择、拖放、嵌套弹窗和导出验收，再建立签名／公证流程。
- **可选扩展**：设备端 OCR、iOS、收藏同步。

新增联网行为、同步和依赖需明确设计与隐私说明，不自动作为上述功能的前提。
