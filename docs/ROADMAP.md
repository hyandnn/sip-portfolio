# Sipfolio 下一步优化顺序

2026-10-07，基于 Mac V0 和用户本轮反馈整理。此文档是后续建议，不代表下列功能已实现。

## 已完成的本轮修正（0.1.1）

- 品牌名统一为首字母大写的 `Sipfolio`。
- 新建与编辑页的类别按钮只显示一个右侧箭头。
- 收藏卡片中的贴纸居中显示。

## 已完成：DeepSeek 在线识别（0.2.0）

根据用户本轮追加指令，已直接接入支持图片的 DeepSeek Flash。可在导入页识别酒名／类别并生成简介、风味与鸡尾酒建议；已有收藏也可补充资料。结果可编辑并由用户确认。真实 API 验证已通过，密钥保存在钥匙串。

## 后续可选：离线文字辅助

优先加入 Apple Vision 本地 OCR，读取瓶身的品牌、酒名字样，再结合明确的类别关键词给出名称／类别候选。预览页让用户选择、修改并确认，识别失败时保持手动录入可用；不得覆盖用户已填写的内容。

OCR 是读取标签文字，不应将提取到的品牌文字直接当作已确认的具体酒款。例如同一品牌的不同年份、版本，需要展示能读到的区分信息，并由用户核对。

Apple 的[文字识别说明](https://developer.apple.com/documentation/vision/recognizing-text-in-images)支持在设备端处理图片。首个识别版本可以保持本地运行，不依赖在线服务。

## 随后：打磨贴纸与收藏体验

- 用实际导入照片检查复杂背景、透明瓶身与多个主体的结果。
- 增加裁剪／重新选主体入口，考虑可调描边和贴纸预览缩放。
- 验证实际点击、拖放、导出、取消和重启，补齐原生操作验收。
- 增加整个收藏册的备份与恢复，完善本地保存失败的反馈。

## 随后：提高酒款知识质量

在线识别与酒款介绍已经加入。下一步可加强具体年份、版本和标签信息的核对，补充可追溯的酒款来源，并打磨低置信度结果的确认体验。

图鉴进度、卡片动画和分享可随后细化；iOS 与同步在 Mac 收藏流程稳定后扩展。

## 图标方向

0.4.0 已按用户选择应用白底可爱像素酒瓶笑脸图标。后续再讨论界面像素风，尚未确定是否对真实酒瓶贴纸做像素化处理。

## 已完成：类别与鸡尾酒集（0.4.0）

类别已改成自由输入和已有收藏的历史提示；新增独立鸡尾酒配方册，从酒瓶推荐喝法创建或手动记录，AI 可填入调配建议后由用户保存。后续可根据实际使用反馈细化配方关联、图片和备份体验，不自动扩展本轮范围。

## 已完成：自动收录与成品贴纸（0.5.0）

用户选择「藏酒册／蒙汗药」。已统一酒瓶卡片高度并减少排序层级；保存酒瓶可自动收录已确认的推荐喝法，同名合并并关联多瓶。公开接口联网补充参考配方和成品图，本机生成贴纸并保存来源，允许调整主体／导入自己的照片。已验证真实公开资料获取和透明抠图，以及普通应用的 Dock 启动策略。

下一轮可根据使用反馈细化不同配方版本和成品图匹配，继续讨论界面像素风；本轮没有自动扩大至云同步或公开分发。

## 已完成：原图与页面精简（0.5.1）

按用户反馈将「藏酒册」更名为「藏酒屋」，删除两页顶部重复的中文收藏册标题，排序选项改为纯文字。蒙汗药改用保留背景的原图与统一图框；联网取图和自己的成品照片均停止抠图，已有原图直接可用。酒瓶贴纸与像素风后续讨论范围保持原计划。

## 已完成：整体像素风与图片可用性（0.6.0）

用户已明确授权像素界面与图标重做。各应用页面改为统一中文像素字体、奶油／薄荷／莓紫配色、阶梯框与方块阴影，新笑脸酒瓶图标已应用。照片仍保留真实内容。CocktailDB 图片可用性不再依赖 CC 确认必须为 Yes，实际 Martini No 字段的联网图片流程已验证，来源与真实确认状态保留。
